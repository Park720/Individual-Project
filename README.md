## Original Website
- instagram (https://www.instagram.com)

## How to run the project locally
- Clone the repository
- npm install
- npm run dev

## Features
- Scrollable Feed with visual contents
- Interactable tab with likes and comments
- Navigation bar that allows users to move around Home(feed),search, and user profile

## 1. What interactive feature(s) you implemented
    The website allows user to search from a list of different profiles using a text input on the Search Page.
    User can like and leave comments on existing posts using React State(like counter and array based state(comment))
## 2. Why you chose this interaction
    I chose this interaction because I thought searching for users is quite frequently used in instagram when searching for friends. Also, I believe one of the most important feature of instagram is the direct response by like and comments. Since these features are key to SNS, I chose to implement these interactions.
